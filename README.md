# 🛡️ Cyber Attack Detection

A Machine Learning based Cyber Attack Detection System that identifies network traffic as **Benign** or **Cyber Attack**.

## 📌 Project Overview

This project uses Machine Learning techniques to detect potential cyber attacks from network traffic data. The system preprocesses network traffic features and uses a trained Machine Learning model to classify the traffic.

## 🚀 Features

- Detects suspicious network traffic
- Classifies traffic as Benign or Attack
- Data preprocessing and cleaning
- Machine Learning model training
- Prediction using the trained model
- Streamlit application for user interaction

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Joblib
- Streamlit
- Machine Learning

## 📂 Project Structure

- app.py — Streamlit application
- predict.py — Model prediction
- train_model.py — Model training
- test_dataset.py — Dataset testing
- requirements.txt — Required Python packages
- image.png — Project image
- README.md — Project documentation

## 📊 Dataset

The project uses the CIC-IDS-2017 dataset, which contains network traffic data including benign traffic and different types of cyber attacks.

## ⚙️ Installation

Clone the repository:

git clone https://github.com/akkenadivyadurga-netizen/Cyber-Attack-Detection.git

cd Cyber-Attack-Detection

Install the required packages:

pip install -r requirements.txt

## ▶️ Run the Application

Run the Streamlit application:

streamlit run app.py

## 🔮 Prediction

The predict.py script loads the trained Machine Learning model and performs predictions on network traffic data.

## 🎯 Objective

The objective of this project is to demonstrate how Machine Learning can be used to detect cyber attacks from network traffic and support network security.
