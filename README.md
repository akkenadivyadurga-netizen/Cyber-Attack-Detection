# 🛡️ Cyber Attack Detection

A Machine Learning based Cyber Attack Detection System that identifies network traffic as **Benign** or **Cyber Attack**.

## 📌 Project Overview

This project uses Machine Learning techniques to detect potential cyber attacks from network traffic data. The system preprocesses network traffic features and uses a trained Machine Learning model to classify the traffic.

## 🚀 Features

- Detects suspicious network traffic
- Classifies traffic as Benign or Attack
- Data preprocessing and cleaning
- Machine Learning model training
- Prediction using the trained model
- Streamlit application for user interaction

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Joblib
- Streamlit
- Machine Learning
